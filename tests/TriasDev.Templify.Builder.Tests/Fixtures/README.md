# Test fixtures

`TemplifyEmbedTest-Regular.ttf` is a modified version of **Carlito Regular** (tyPoland Lukasz Dziedzic, SIL Open Font
License 1.1, see `OFL.txt`), used only by the font-embedding tests:

- subset to Basic Latin (U+0020–U+007E), without hinting and layout features;
- renamed to the family "Templify Embed Test", because "Carlito" is a Reserved Font Name and because the tests need a
  family that no machine has installed (LibreOffice ships Carlito itself).

The copyright and licence entries of the font's name table are kept.
